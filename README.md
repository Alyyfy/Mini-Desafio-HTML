# 💼 Portfólio Web — Desenvolvimento de Sistemas

Projeto desenvolvido como atividade prática do curso de **Desenvolvimento de Sistemas no SENAI**, com o objetivo de criar uma página de **Portfólio / Currículo Web** utilizando HTML5 semântico.

---

## 📋 Descrição do Desafio

O desafio consiste em desenvolver uma página de portfólio de um desenvolvedor, organizando informações pessoais, habilidades, projetos e um formulário de contato.

A página deve reproduzir a estrutura apresentada no modelo fornecido, utilizando **HTML5 puro**, com organização semântica e elementos funcionais.

---

## 🎯 Objetivo

Criar uma página HTML:

- 🧱 Estruturada corretamente com HTML5;
- ♿ Organizada de forma semântica;
- 🧑‍💻 Apresentando informações pessoais e profissionais;
- 💻 Exibindo habilidades e projetos;
- 📋 Contendo um formulário de contato funcional;
- 🔗 Possuindo navegação interna entre as seções.

---

## ✅ Requisitos do Projeto

### 🏠 Cabeçalho e Navegação

O projeto deve possuir:

- Título principal com nome e cargo;
- Menu de navegação;
- Link para a seção **Sobre**;
- Link para a seção **Projetos**;
- Link para a seção **Contato**.

Exemplo:

```html
<header>
    <h1>Nome - Estudante de Desenvolvimento de Sistemas</h1>

    <nav>
        <a href="#sobre">Sobre</a>
        <a href="#projetos">Projetos</a>
        <a href="#contato">Contato</a>
    </nav>
</header>
